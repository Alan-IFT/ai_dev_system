**执行（两条命令，可复跑）**：

```
ls -A .git/hooks/ | grep -v '\.sample$' | wc -l   →  0
ls .github/workflows 2>/dev/null | wc -l          →  0
```

**结论（三条，均不漂）**：

1. **本仓库零启用的 git 钩子、零版本化 CI。**
2. **按 31-P1 的四级，本仓库的「约束」级与「警告」级都是空集。** 唯一实际运行的阻断是人工调用的两个脚本（`check_normative_force.py`、`linkcheck.py`），它们不在任何自动通道上——按「动作空间被该通道穷尽」的判据，**它们连"警告"级都不成立，因为绕过它们不需要任何动作**。
3. **[015 §2.4](015-图工程三原则综合审计.md) 预写判据的后半句"对检查器可得"不成立**（021、022 各自独立查到）。

> **成立条件**：以上三条只对本仓库当前工作副本成立，且只覆盖"版本化的自动通道"。执行者本地私有的钩子不可见，**这一格记未定，不折算**。

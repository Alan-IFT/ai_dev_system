（这个数是本轮**唯一**的正文变化，也是本批最该准的一个数——一批以"正文 0 行改动"为卖点的产出，正文那一格自己算错了符号方向。）

### F-02｜删「六条」写下的理由，在改后并未被消除——失效模式只挪了一跳

[D-057 登记行](../决策日志.md#effective-register)逐字给的理由：

> 写死条数会在下一次增改时把新增的那一条**静默排除**出「对一切运行成立」

而改后的规范句是逐字引 [00 §3](../00-总览.md#default-scope)：「**§5 各条**不变量、控制平面与责任平面的原则对一切运行成立」。**「§5」指的是 00-总览 自己的 §5**，而 00 §5 现读逐字：

```
grep -n '^## 5' docs/00-总览.md   →  77:## 5. 六条不变量
```

节标题「## 5. **六条**不变量」；首句「换任何工具都不变的**六条**」；下面**逐条枚举 1.–6.**。

**于是：加第七条不变量之后，00 §3 的「§5 各条」指向的仍是一份标题写死六条、且只枚举到 6 的清单——新增那一条照样被静默排除，除非同时改 00 §5。** 登记行自己写下的失效模式，在新写法下**没有被消除，只是从登记表挪到了 00 §5**。

顺带（同一形状的第三处）：[架构确定 §5.3](../架构确定.md#invariants) 的节标题逐字也是「六条架构级不变量」。

**改动本身仍是净改善**（"§5 各条"是判据式表述，比"六条"少一个需要同步的点），**但登记行不该把它写成失效模式已被解除**。正确写法：「本轮把登记表这一处从基数改为判据；**同一失效模式在 00 §5 的节标题与枚举、以及架构确定 §5.3 的标题上仍然存在**，本轮不动，记为待处置。」

## 5. 对第 8 点的裁定："保守偏差"的自陈是诚实披露，不是正当化

[031 §6](031-四条待裁的整合与推荐.md) 逐字：「**是，但它写在规则里**」，并给出三条来源与一条代价。**判定：诚实披露。** 四条理由，每条独立可核：

1. **它给的是机制，不是态度。** 三条来源里最硬的一条我现读复核属实——[08 §3](../08-规范效力元治理.md#unmarked-default) 的分向降级表逐字：未标注规则「用它作为**拒绝**、暂停、要求补充证据或升级给人类的理由 → 允许；用它作为**执行**动作、跳过检查、放宽条件或自我授权的理由 → **不允许**」。**每个未定确实在结构上倒向不做**，这是可指认的成因，不是事后解释。
2. **代价写在同一段，而且是最难看的那个。** 逐字：「这扇窗到 2026-12-03 到期时，读数仍是"拦住 0 条"」「**这个代价本文不掩饰**」。正当化的写法会把这句省掉或稀释。
3. **四条各写了证伪路径**：D-072「出现一条实测的『记忆内容 → 控制流』绕道，本判定即被证伪」；D-074「出现一条 pre-commit 能拦住而人工执行确实漏掉的真实缺陷（那将直接证伪『价值未定』里的成立条件）」。**保守若无法被推翻才是正当化。**
4. **最硬的一条：本批把自己最有利的那条保守理由删掉了。** [030](030-四条待裁的独立复验.md) 用四条独立理由证伪了 027 关于钩子"价值为零"的推论，D-074 因此把结论从"价值为零"改写成「**价值未定，成立条件"人工执行率不下降"；而代价确定且已知**」，并逐条列出代价（Gate 合同 + 失效探测 + 豁免留痕，"一行配置"这个标价不成立）。**为保守找正当化的一方不会主动删掉一条对自己有利的理由，再换上一条更弱但更准的。**

**但必须写下两条限制：**
- **这个自陈由做决定的同一批产出自评**（029 写、031 采纳、执行者落地）。按 [30 §2 P5](../30-验证与测试.md)，子原因"生成者与验证者同一"，**它诚实，但它不构成"保守是对的"的证据**——它只构成"偏差已被指认且未被隐藏"。
- **真正的检验不在本批**，031 §6 自己已经写下：「**唯一能改变这一点的动作，本文判定不在这四条里，也不在本仓库里**」。**在 2026-12-03 之前，"三条不做"是否正确这一格记未定，不折算。**

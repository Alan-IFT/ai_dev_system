## 3. 解释与判断（按未定读，子原因：生成者与验证者同一）

**根因不是那几条不合规，是 D-057 的 scope 在两种读法之间没有选**：

- **(甲)** 117 条约束任何在本仓库内作业的人——我，每一轮；
- **(乙)** 117 条作为一份规范生效，采用它的项目须遵守。

**现有生效规则的先例是分开的**：D-014 与 D-015 是元治理与载体类，scope 写 `repo:...`；D-020、D-043、D-047 是内容类，scope 写"本仓库全部规范正文内"——它们约束**文本能写什么**，不约束维护者要做什么。**D-057 把一批内容类规则挂上了元治理类的作用域，这是我上一轮写下的缺陷**（[Case C-026](../失败Case清单.md)）。

按 (甲) 读下去，本仓库得为了编辑 markdown 而建验收条目、Gate 集合、工作项与交接、预声明阈值；按 (乙) 读，D-057 只剩状态变更，三项检验一项也答不了。

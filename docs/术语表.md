# 术语表

状态：`v0.6-theory-draft`
governed_by：D-014、D-029、D-031、D-032、D-034、D-039、D-047

| 术语 | 本规范中的定义 |
|---|---|
| Prompt Engineering | 设计模型指令、示例与输出要求，改善一次或一类调用。 |
| Context Engineering | 为每次推理选择、组织、维护全部可见信息。 |
| Harness | 围绕模型的知识入口、状态、工具、权限、工作流、记忆、验证、观测与评估环境。 |
| Workflow | 由系统预定义路径编排模型和工具的流程。 |
| Agent | 根据环境反馈，由模型动态选择行动和工具的系统。 |
| Claim / 主张 | 带范围、版本、环境和时间的待判断陈述。 |
| Source / Citation / 来源或引用 | 用于追溯研究、需求或说明出处的材料；引用本身不证明交付已生效。 |
| Source of record / 权威记录源 | 对某类意图、定义或状态具有治理权限的载体。 |
| Observation / 观察 | 在明确时间、环境和方法下直接读取到的结果。 |
| Validation result / 验证结果 | 对工件执行指定过程后得到的结果，如本次测试运行。 |
| Acceptance evidence / 验收证据 | 将验收 ID、版本、环境、过程、结果、工件和限制绑定的证据包。 |
| Context / 上下文 | 当前一次推理实际可见的 Token 工作集。 |
| State / 状态 | 带身份、版本和时间的任务阶段、阻塞与下一步。 |
| Knowledge / 项目知识 | 经治理并带 owner/source/scope 的需求、架构、契约、规则与说明。 |
| Long-term memory / 长期记忆 | 从过去保留供未来召回的观察、经历、偏好或候选经验；不天然权威。 |
| 置信态 / Confidence tier | 记忆或知识条目随附的使用方式等级：强（可驱动执行）、弱（只提示风险）、影子（只助发现与背景召回，不得单独作为执行依据）；由来源节点与验证证据决定，不等于检索相关度。 |
| 派生知识 / 经验知识 | 两类非权威知识工件。派生知识由代码或文档机械生成（索引、摘要、地图），只能作为声明的缓存存在：绑定源版本、机械对账，过期默认不作事实使用；经验知识由运行观察提炼，带 scope、产生事件与版本，scope 内源变化触发复核而非判过期。 |
| Compaction | 把即将超限的会话历史压缩成恢复摘要；不是知识或长期记忆。 |
| 隔离原语 | 为主线减负的三类基本手段：委托（不继承历史、只回结论，须声明是否继承治理规则，未声明视为不继承且只读）、分叉试探（继承全部历史、产物不回流、用完即弃）、压缩外部化（主线自身瘦身，把工作集移出窗口）；按任务是否依赖已有上下文、产物是否回流选择。 |
| Progressive Disclosure | 先给轻量入口，再按任务逐层加载详细信息。 |
| Default Context Contract | 唯一声明默认与按需上下文路径、版本和冲突处理的合同。 |
| Gate / 闸门 | 由检查器执行，条件不满足时会阻止动作或状态转换的约束。 |
| 事实门禁 / 人工判断检查点 | 按判据性质区分的两类 Gate：事实门禁的判据是可从工件或环境直接观察的确定事实，可阻断，数量上限由误报率约束；人工判断检查点需要人的判断，数量上限由判断带宽约束，应集中在少数状态转换处并记录耗时、频率与否决率。判据为代理指标的检查只能提醒或产生候选，不得阻断。 |
| 屏障 / Barrier | 失败回边语义：上游检查失败后，同一任务的后续写入动作全部停止，只允许诊断性读取与判定；重试预算按失败所在层分配。 |
| Waiver / 豁免 | 有批准人、范围和失效时间的 Gate 临时例外。 |
| 生效登记表 / Effective register | 决策日志中登记全部`试行`/`已接受`规则及其批准字段的表，是查询规则效力的唯一权威位置。 |
| blocks / grants | 一条生效规则的两个独立效力方向：阻断某动作或状态转换，与授权本不被允许的动作。批准 blocks 不产生 grants。 |
| 分向降级 | 未标注效力的命令式规则的默认处理：可作为拒绝、暂停或升级的理由，不可作为执行或自我授权的理由。 |
| UNDETERMINED / 未定 | 判定结果的第三态：既非 PASS 也非 FAIL，必须停止并报告，聚合评分不得把它折算为通过。产生于条件所依赖的生效规则集合为空；也用于验证层未执行、外部写入结果未知、审批应答缺席、生成者与验证者同一、工作单元交接缺字段的情形（D-029）。子原因用括号列出（阻塞 / 未执行 / 无法核验 / 结果未知 / 应答缺席 / 生成者与验证者同一）。 |
| 外部 / 内部（边界） | 满足任一条即为**外部**：其权威记录源不由本项目治理；或其上已发生的事我们不能单方面撤销。其余为内部。标注对象是权威记录源（见[11 项目知识](11-项目知识.md)）与工具（见[24 工具与执行环境](24-工具与执行环境.md)）。判不清时按外部处理。 |
| 第六条不变量 / 边界外不由我们控制 | 对外部对象的四条约束：读只引用不复制；写只在声明的阶段窗口内、须幂等、须留回执，结果未知即记未定、未成功进待补偿；可用性不保证，依赖分必需与推荐两档；唤醒不等于授权。默认取向为跨边界多读少写。全文见[架构确定 §5.3](架构确定.md#invariants)。 |
| 宪法性批准 | 元规则无法援引上游决策使自身生效时，由项目所有者直接批准并公开声明无上游依据的批准方式。 |
| Readback / 回读 | 写入或发布后，从目标系统重新读取实际状态。 |
| Trace / 轨迹 | 一次任务运行中模型调用、工具调用、Gate、审批、交接与结果的记录，须可还原为带父子关系与时间区间的调用树，重试与中断为独立节点，注入内容可按来源回看；纯时间序列不构成轨迹。导出与聚合视图是派生投影，验收证据须回读原始记录。 |
| Eval / 评估 | 用版本化 Case、grader、指标和重复策略衡量行为及回归。 |
| ADR | 记录重要决策背景、备选、选择、取舍、效力和验证。 |
| Runbook | 面向重复情境、仍需判断的操作说明；与预批准动作集不同。 |
| 预批准动作集 / Pre-approved action set | 由具名责任人事先枚举并批准、可在声明的触发条件满足时由执行者机械触发的动作集合；与 Runbook（仍需判断）和 Gate（阻断）不同。其变更是慢变、可审计的授权变更，并附抽样复核。 |
| Skill | 按触发条件加载的可复用任务方法与资源。 |
| ACI | Agent-Computer Interface，即 Agent 面对的工具与环境接口。 |
| Ground truth | 当前环境可直接观察或复现的事实；仍受版本、范围和测量限制。 |
| Add / Thin | 基于真实任务和 eval，为 Harness 增加能力或删减失效能力。 |

注意：不同产品常把知识、记忆、状态和上下文混用；本规范按治理职责而非存储技术命名。

## 0. 总原则（不可违反）

1. **一切新增内容都是`提议`**。不得写"已接受/已生效/必须遵守"等效力声明；章节头 `governed_by` 只列决策 ID。文档状态行改为 `v0.6-theory-draft`。
2. **不修改已接受决策的正文**：`docs/08-规范效力元治理.md`、`docs/09-跨工具通用性.md` **一字不改**。涉及它们的修改全部登记为候选决策（D-040、D-041、D-042），由主 Agent 写入决策日志。
3. **D-020 写法**：正文只写语义不变量。禁止具名工具、文件名、目录名、钩子事件名、字段名、格式名。凡"落地方式"只能写机制类型（静态指令 / 条件加载规则 / 运行时拦截 / 检查器 / 权限与隔离配置 / 外部状态存储 / 人工检查点 / 工作流固定步骤），且可并列时须并列 ≥2 型。
4. **D-026 反膨胀**：每个文件给定净增行数上限（见 §3）。优先**改写现有条文**吸收新语义，其次合并，最后才追加。删除被替代的旧句子。不得复制其他章节已有的定义（引用即可：见 03 §8）。不得在正文出现具体数字阈值、效果数字、角色数量。
5. **不复制效力状态值**：正文里不得出现"D-xxx（已接受）/（提议）"之类状态副本（D-014 阻止第三处副本）。只写 D-xxx。
6. **术语一致**：使用 `docs/术语表.md` 术语。本轮统一：第三态一律称 **未定（UNDETERMINED）**，其子原因用括号列出（阻塞 / 未执行 / 无法核验 / 结果未知 / 应答缺席 / 生成者与验证者同一）。不使用 blocked/NOT_RUN/unknown 作为正文术语（可作括号内子原因的中文）。新术语：**预批准动作集**、**事实门禁 / 人工判断检查点**、**置信态（强 / 弱 / 影子）**、**派生知识 / 经验知识**、**隔离原语（委托 / 分叉试探 / 压缩外部化）**。
7. 修改后的文件写到 `（工作区）docs_new/<同名文件>`（先 `cp` 原文件再改）。不得修改 `（工作区）docs/` 原件。完成后在 `（工作区）docs_new/CHANGELOG-<文件名>.md` 写变更清单：每条 = 章节 § ｜ 操作 ｜ 依据（T?-S??）｜ 行数变化；末尾给出文件总行数前后对比。
8. 保留全部锚点 `<a id="...">`，保留所有相对链接；新增章节若被其他文件引用需给锚点。
9. 每处新条文若来自单团队 n=1 或推理，措辞用"应""可"而非"必须"；来自一手多来源者可用"必须"。

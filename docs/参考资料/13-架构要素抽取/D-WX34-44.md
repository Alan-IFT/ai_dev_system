### WX-35 AI时代不吐不快的12条判断（类型：O1；场景：个人/团队编码 Agent 使用观点）

- **部件关系**：人 → 知识库：补齐与更正（控制，"不能放心让它自助维护"）；AI → 知识库：回顾发现问题（数据，仅发现）；人 → 模型：失败时换模型/补上下文/换 prompt 再试（控制）；AI → 工具：开发确定性工具，之后工具替代推理（控制）；场景 → 团队资产：bottom-up 从具体场景引出（"AI 不是底座"）。
- **不可省略**："没有判断力会被忽悠"——人的审核（第 4 条）；"知识本身的补齐与更正才是重点且依赖人把关"（第 12 条）；"一头一尾"（意图澄清与验收）是短板但不可绕过（第 5 条）。
- **分层 / 演进**：提效三层 个人→团队→业务（归因难度递增）；资产沉淀 bottom-up（研发管线知识≈新人手册 → 业务知识按需 → 功能 agent 从问题出发）；确定性任务从推理"降级"为工具。
- **失败归因**：AI slop 腐化 → 无全局审核（人）；停在失败样本 → 未改变输入变量（上下文装配/模型）；方案成本过高 → 人判断缺；AI 编造知识补全 → 人把关缺（长期记忆/项目知识治理）；确定性任务每次跑推理输出不稳定 → 工具缺（工具与执行环境）；验收排队 → 人带宽（验证与测试）。
- **证据形态**：纯文字观点；一张 AI 生成截图（且被卡片证实混入非原文内容）；无实测。

## 可支持的观察

- 交付系统的瓶颈常在环境是否被 Agent 正确理解，而不仅是模型能否生成代码。
- 入口应像“地图”，短而可导航；仓库内版本化文档应成为事实记录，而不是把大段手册塞进初始上下文。
- 对必须遵守的架构不变量，机械检查通常比反复提示更可靠。
- UI、日志、指标和工作区隔离也应面向 Agent 可读。
- Harness 会累积熵，应像代码一样清理失效或重复机制。

## 边界

文章描述的是特定内部绿色项目、特定团队和有限时期的经验。它不能证明所有团队都应采用低阻塞合并、同样的文档结构或同样的 Agent 自治程度。上述落点仍是待项目验证的候选。

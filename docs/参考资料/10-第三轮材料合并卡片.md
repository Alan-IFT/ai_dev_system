# 第三轮材料合并卡片（ATT-E ～ ATT-Q）

状态：`v0.6-theory-draft`（第四轮已更正 4 行，见 004 §4）
governed_by：D-014
last_verified：2026-09-02

本卡片刻意合并 13 份材料，不逐份建卡。理由见[输入材料 003 §1](https://github.com/Alan-IFT/dsh-project-std/blob/archive-pre-ts-refactor/docs/%E5%BD%92%E6%A1%A3/%E8%BE%93%E5%85%A5%E6%9D%90%E6%96%99/003-%E7%AC%AC%E4%B8%89%E8%BD%AE%E8%B5%84%E6%96%99%E7%BB%BC%E5%90%88%E8%AE%B0%E5%BD%95.md#registry)：13 张独立卡片将产生约 250 行高度重复内容，正是 ATT-N 所描述的膨胀机制。

## 核实状态

全部 13 份为二手转述或实践笔记。其中多份引用的官方来源标注日期在 2026-06 至 2026-07，**超出 AI 的可靠知识范围，AI 未能独立核实**。引用其中任何一条前须回到一手来源。材料中的全部效果数字不作为跨项目结论。

## 可复用的概念工具（去掉数字与工具名之后剩下的部分）

| 概念 | 一句话 | 出处 | 本规范中的候选归属 |
|---|---|---|---|
| 组织摩擦 | 交付周期 = 价值创造时间 + 组织摩擦时间；后者不集中在任何一个环节 | ATT-E | D-022 |
| 状态由事件推断 | 人工汇报的状态必然失真，使阶段耗时等指标失去统计意义 | ATT-E | D-016 修正、D-022 |
| 三层评价 | 局部输出 → 行动路径 → 整体结果，前者改善不蕴含后者改善 | ATT-F | D-025 |
| 噪声大于效果时 A/B 不成立 | 被测机制效果量小于执行路径波动时端到端 A/B 不成立（本规范由 ATT-F 复测方差推断，非作者主张）；"退回可复现的组件级对照"是 ATT-L 的主张，且只对局部输出层有效——改变模型所见的机制仍须报路径层 | ATT-F（数据）、ATT-L（方法） | D-025（第四轮更正来源） |
| 有效能力为交集 | 用户授权 ∩ Agent 配置 ∩ 技能策略 ∩ 会话范围 ∩ 工具侧强制 | ATT-G | D-027 |
| Prompt 不是安全边界 | 措辞只能引导选择，边界必须由工具或沙箱层强制 | ATT-G、ATT-M | 强化 05 章 §1 |
| 证据只读 | 原始证据默认不可被 Agent 覆盖，避免模型"修正"证据 | ATT-G | D-009 强化 |
| 补偿面 | 每个组件编码一条"模型做不到什么"的假设；假设随模型变强而过期（一手出处为非对照观察："有理由相信 + 逐个移除观察"）；到期规则多数反转为负作用而非仅冗余 | ATT-O、ATT-H 图 008 | D-021 |
| 补偿面迁移而非收缩 | 更强模型消灭某些脚手架，同时解锁需要另一类脚手架的能力 | ATT-O | D-021 |
| 规则须绑定失败 | 说不清防什么的规则，从写下那一刻就无法被淘汰 | ATT-H | D-021 |
| 冗余是负资产 | 多写一句可能覆盖模型更好的判断、缩小搜索空间、导致过度触发 | ATT-H、ATT-N | D-026 |
| 信息源头三分（原误名"四层归属"） | 信息源头在公开语料/在代码与运行环境/在人的头脑与组织结构，决定该不该写；第四轮发现间隙：运行观察提炼的经验不属任何一类 | ATT-H | D-020、D-040 |
| 四层归属 L0～L3 | ATT-H 的另一条轴：L0 模型本体 / L1 通用 Agent 机制（最不保值）/ L2 组织特有 / L3 判断与授权（永不内化）；自建 Harness 的立足点在 L2/L3 | ATT-H（图 009，前三轮丢失） | D-021、D-013 |
| 责任不可转移 | 只有人能继承后果；这一条连理论上都无法被技术进步消解 | ATT-H | D-020、D-024 |
| 验证能力是自主度上界 | 能交出的自主度上限等于能廉价可靠验证的量，与任务重要性无关 | ATT-H | D-024 |
| Gate 受判断带宽约束 | 判不动的 Gate 等于没有，且更糟——制造"已经审过"的假象 | ATT-H；对策不是减 Gate 而是让每个 Gate 便宜到能真判（裁决项/证据/推荐前置，全文与 diff 作附录），呈现格式属 Gate 合同（第四轮补） | ATT-H | D-024 |
| 第二个事实来源 | 与代码并存的描述文档会过期，比没有文档更危险 | ATT-H | 强化 01 章 §5 |
| 注意力 U 形 | 长文档中间区域的遵循率显著低于首尾 | ATT-N | D-026 |
| 隐性冲突静默择一 | 规则间有张力时模型不报错，选一条丢一条 | ATT-N | D-026 |
| 正向优于否定 | 否定指令需先激活被禁概念；应写"只做 Y"而非"不要做 X" | ATT-N | D-026 |
| 参考文件一致性 | 模板/示例违反规则时，模型在"听规则"与"照模板做"之间摇摆 | ATT-N | D-026 |
| 自动修复必然膨胀 | 局部视角 + 安全追加偏好 + 无健康度概念 + 拆掉人的懒惰这个刹车 | ATT-N | D-026 |
| 目标失明 | 系统会用背叛目标初衷的方式移动被赋予的指标（ATT-J 的客服案例为 Perez 的说明性示例，非实测；真实实例见 WX-04 F7、WX-34 F5） | ATT-J | D-023 |
| 现实锚点 | 全部节点互相引用模型结论而无一碰现实，是更精致的自嗨 | ATT-J | D-023 |
| 工作图/角色图 | 任务如何拆合可快变；谁有权改什么必须慢变可审计 | ATT-J、ATT-G | D-028 |
| 契约声明"是什么"+ 探测"在哪" | 通用契约不含路径，路径由探测生成映射，从而跨载体复用 | ATT-P | D-020 |
| 审查者不得自审 | 生成者不能自行拉起审查者；评价者与被评价者分离是结构问题非能力问题 | ATT-P、ATT-O | 强化 05 章 §6 |
| 编辑边界 | 分发副本与源之间必须声明哪些文件可改、哪些同步覆盖 | ATT-P | D-020 |
| 三原则 | 什么时候给、给谁看、保留多久 | ATT-L | 强化 03 章 |
| 上游收集一次 | 最贵的冗余是每个角色各自重新发现同一份信息 | ATT-L | 强化 03 章 |
| 四层嵌套非替代 | 外层不取消内层；故障应先定位层级再施加对应层修复 | ATT-Q | D-020 |
| 先可靠后自动 | 单任务不可靠时上多任务自动化，只把不可靠放大到系统级 | ATT-Q | D-010 强化 |

# CoALA：Cognitive Architectures for Language Agents

原文：[OpenReview / TMLR 2024](https://openreview.net/forum?id=1i6ZCvflQJ)；用户提供的 [PDF](https://arxiv.org/pdf/2309.02427)  
source_id：`SRC-COALA`  
类型：A2（同行评审概念框架）  
访问核对：2026-09-01

## 可支持的观察

- 可从工作、语义、情节、程序记忆以及内部/外部行动来描述语言 Agent 的认知架构。
- 记忆、检索、推理、学习和环境反馈可被看作一个决策循环中的不同部分。

## 在本项目中的落点

- [CoALA 概念视角](../12-记忆与知识治理.md#coala-lens)用它检查职责完整性。
- 本规范运营上仍将项目知识与非权威长期记忆分开，避免 PRD/架构被模型摘要覆盖。

## 边界

CoALA 是概念框架，不证明必须建立四个数据库，也不提供可直接采用的权限、冲突、保留期或抗污染治理方案。

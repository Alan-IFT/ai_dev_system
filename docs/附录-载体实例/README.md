# 附录：载体实例

governed_by：D-014、D-020

**本目录不属于规范正文，不产生任何执行、阻断或授权效力。**

这里存放的是"某条语义要求在某一种具体工具/载体上的一种实现"。它们的作用只有两个：

1. 证明对应的语义要求确实可被机械化（可行性证据）；
2. 作为反面参照，展示"载体绑定"具体长什么样——同一条语义要求换一个工具就要重写。

## 处置说明

`check_normative_force.py` 写于 2026-09-02，当时被写入 D-014 §9 作为规范的一部分。2026-09-02 晚提出跨工具通用性要求后，它被移出规范正文——因为规范只能要求"效力标注必须可机械校验"（语义不变量），不能规定用哪种语言扫描哪种文件（载体绑定）。

本目录内容随时可整体删除而不影响规范。项目侧对模板/工件的检查器可校验"身份、效力、版本、环境、责任字段是否存在"，但不得按文件是否存在或数量打分（D-041 提议）。

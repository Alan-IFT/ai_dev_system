# 附录：机制类型清单（D-020 §6 探测提示的并列形态）

governed_by：D-014、D-020、D-108
last_verified：2026-09-02

**本文件效力为零，不属于规范正文。** 用途只有一个：写规范或做项目映射时，按维度检查一条探测提示是否并列了 ≥2 种**机制类型不同**的落地形态（D-020 §5/§6 的硬性检验）。本表只列类型，**不列工具，不维护映射表**（D-020 §7）；每种类型至少来自一份一手文档或运行观察（来源为第四轮卡片，见括号）。新增类型须来自一手观察；本表随工具演化复核，过期实例登记见[载体过期登记](载体过期登记.md)。

| 维度 | 并列的机制类型（互不相同） | 观察来源 |
|---|---|---|
| 常驻指令注入 | ① 提示词前缀型：约定文件在会话开始拼入系统指令 ② 持久事件型：指令作为会话日志事件注入，随回放与压缩存续 ③ 地图-指针型：短入口只列指向权威源的指针 ④ 预算裁剪型：总字节预算，超限先整份丢弃更宽泛来源，并把裁剪事实告知模型 | WX-25/13；WX-29；WX-05/40；WX-29 |
| 条件加载 / 方法 | ① 路径触发：读到匹配文件时加载 ② 元数据常驻 + 正文触发的多级披露 ③ 人工触发、禁止模型自触发 ④ 两阶段路由：规则/分类器预筛 → 模型精选 → 只注册被选方法允许的工具 ⑤ 预执行注入：加载时先跑命令把输出内联 ⑥ 排除条件参与路由 | WX-25；WX-13；WX-25；WX-30；WX-25；WX-39 |
| 长期记忆 | ① 手工维护的记忆工件 ② 自动记忆：运行时自决保存/召回，或按工具分桶带保留期自动写入并在会话开始注入 ③ 无内置记忆：只追加日志 + 跨会话全文检索，记忆靠扩展 ④ 派生摘要 + 来源链接 ⑤ 会话历史只作候选原料（提取 → 审批 → 晋升） | WX-41；WX-15/17；WX-29；WX-22；WX-01 |
| 状态 | ① 日志投影型：目标、计划、待办、当前权限预设均从只追加日志倒推，无第二份存储（"模型可见即已记录"） ② 独立状态工件 ③ 文件名/目录前缀即状态 ④ 任务系统字段 ⑤ 产物清单带多态校验 ⑥ 会话创建时冻结的不可变范围 ⑦ 每次调用从目标地址推断环境并在确认框回显 | WX-29；本规范模板；WX-15；WX-34；WX-30；WX-30；WX-17 |
| 权限 | ① 声明式允许/拒绝列表（可能只覆盖内建工具、无匹配默认允许——反例） ② 沙箱模式 × 审批策略两条正交旋钮 ③ 可插拔审批应答链：无应答 = 拒绝，"永不询问"先于任何应答者生效 ④ 网关冻结 + 工具侧复核双检 ⑤ 执行身份本身不具备该类权限 ⑥ 单用途系统账号 + 出站白名单 + 通信对象白名单 ⑦ 工具可见性过滤：只过滤继承工具、自注册豁免——是可见性不是安全边界 ⑧ 多档渐进分级：静默放行 / 静默审计 / 事前确认 / 标注不可逆确认 | WX-30；WX-29；WX-29；WX-30；WX-15；WX-40；WX-29；WX-17 |
| 工具暴露 | ① 静态枚举：每个工具声明对模型的暴露方式 ② 运行时按作用域链就近覆盖计算可见集 ③ 按方法选择结果动态注册 | WX-29；WX-29；WX-30 |
| 拦截 / 扩展 | ① 外部进程钩子：宿主在动作前后调用外部命令，返回结构化决定并可改写入参（字段名与决策值集各宿主不同） ② 进程内类型化事件：前置检查 / 内置防护 / 执行 / 后处理分段注册，守卫只能拒绝或弃权且不可重排到授权之后（fail-closed 单调守卫） ③ 桥接：一种宿主直接运行另一家的钩子清单 ④ 静态指令"强制走链"（名义强制、提醒级） ⑤ 宿主接口只支持阻断不支持注入 ⑥ 靠解析命令字符串识别工具（可被改写逃逸——反例） | WX-25/17；WX-29；WX-29；WX-22/17；WX-42；WX-17 |
| 子执行者 | ① 不继承历史、只回传结论的委托 ② 继承全部历史、产物不回流的分叉 ③ 隔离委托跳过项目治理规则（风险形态） ④ 权限默认继承而工具不继承，交集未重算（风险形态） ⑤ 独立身份 + 可通信对象白名单 ⑥ 运行时自定义扩展仅存内存、重启即清 | WX-25；WX-25；WX-25；WX-30；WX-40；WX-29 |
| 观测导出 | ① 进程内事件订阅插件建调用树 ② 外部常驻采集器读本地会话文件 + 钩子脚本 ③ 应用内 SDK 直传 ④ 原生遥测缝：出站记录过脱敏链、规则出错即扣留、默认不共享、后端须披露共享状态 ⑤ 只追加本地日志为权威，导出是有损投影须带缺口标记 | WX-37（含 DSH 一手） |
| 压缩 / 外部化 | ① 清空 ② 确定性截断 ③ 摘要 ④ 外部化为交接件 ⑤ 压缩前事件强制外部化 ⑥ 过大工具结果溢出到外部存储 | WX-01；WX-01；WX-01；WX-01；WX-25；WX-29 |

使用方式：某条正文探测提示若只举了本表某维度的一种类型，即触发 D-020 反例表第 4 行（只举一种形态），应补第二种类型或移出正文。本表中标"反例"或"风险形态"的项不是推荐做法，只用于说明该类型存在。

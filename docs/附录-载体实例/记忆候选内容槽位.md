# 附录实例：记忆候选的提示内容槽位

governed_by：D-014、D-020

**本文件不属于规范正文，不产生任何执行、阻断或授权效力。**

从 [12 记忆与知识治理](../12-记忆与知识治理.md) §2 移出（2026-09-03，删减审计 M14）。移出理由：原文自述"形态由项目定，不作必填"，一份非必填的字段清单出现在「最小职责」里，形式与内容直接矛盾。候选的**最小身份**仍是 12 §1 的必做项，本表只是身份之外的可选提示槽位的一种形态样本。

## 槽位样本

| 类别 | 建议槽位 |
|---|---|
| 通用 | 定义之外的真实样例；反例与易混项；适用前置条件；历史误判 |
| 经验类 | 决策理由；被排除路径；验证方式 |
| 组织关系类 | 显式列出待补齐项 |

换一种记忆载体，这张表就要重写；正文只保留"候选须有最小身份"这一条语义要求。

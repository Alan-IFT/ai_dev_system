# 10 意图与验收

状态：`v0.7-theory-draft`
平面：知识
governed_by：D-002、D-009、D-037
用途：把"要做什么、做到什么算完成"固定成一份带稳定 ID、可被下游机械派生的条目清单。

## 1. 最小职责与接口

- **它必须做到的**
  - 维护一份带稳定 ID 的验收条目清单；条目描述可观察结果、目标环境与风险，不写实现方式。
  - 把每条被接受的对抗性发现转为条目并给 ID；未转 ID 即视为未被接受。
  - 在确认点冻结条目语义；此后的改动记为验收变更并回到原批准人。
  - 作为下游唯一派生源：工作项与验证用例都从这一份清单派生。
  - 为每个条目声明批准人与验收人。
  - 保持"实现完成"与"已验收"两个概念不互相冒充。
- **从别的部件拿什么**：从[40 人的检查点与授权](40-人的检查点与授权.md)拿意图确认、冻结授权与验收变更的批准；从[30 验证与测试](30-验证与测试.md)拿逐条裁定结果与被接受的对抗性发现；从[33 评估与演进](33-评估与演进.md)拿真实失败转来的新条目候选。
- **给别的部件什么**：给[20 状态工件](20-状态工件.md)与[21 调度与拆分](21-调度与拆分.md)切片划分依据；给[30 验证与测试](30-验证与测试.md)用例必须覆盖的条目 ID 集合；给[32 证据与追踪](32-证据与追踪.md)证据绑定的锚点；给责任平面待确认与待变更的条目。
- **它自己维护什么**：条目清单、每个条目的冻结状态、验收变更记录及其批准人。
- **未决**：本章无独有待决项；条目冻结后自动路径是否继承人工确认豁免，随守卫语义在[31 守卫与权限边界](31-守卫与权限边界.md)登记。

## 2. 原则

- **P1 验收条目是意图的唯一派生源。** 工作项与验证用例从同一份带 ID 的清单派生，下游不得重新解释意图，也不从聊天灵感直接开工。｜防的失败：需求与测试各自漂移 ｜删除条件：写不出（责任结构型：意图归属于人，"要做什么"不能由下游的实现者或生成者重新解释）
- **P2 条目带稳定 ID，描述可观察结果。** ID 稳定，证据、用例与状态转换才能互相回指；条目写目标环境与风险。｜防的失败：完成主张无法绑定到具体验收；条目改写后旧证据失去指向 ｜删除条件：起始档——"ID 稳定以供互相回指"自 L1 起才有对象（L0 单会话内清单本身即锚点，形态见 §3）；"描述可观察结果"对一切档成立，写不出（责任结构型：什么算做完只有人能定义）
- **P3 被接受的对抗性发现必须取得自己的 ID。** 发现进入同一份清单，与其它条目同等对待。｜防的失败：分析结论停在报告里无人跟进 ｜删除条件：分析结论能被机械追踪到对应的修复与验证时可删这一步
- **P4 确认即冻结语义。** 冻结后语义不随实施调整；实施期的修改记为验收变更并回原批准人，不由实现者就地重写。｜防的失败：实现者弱化验收让自己通过 ｜删除条件：写不出（责任结构型：改变"算做完"的定义是一次授权变更，权属于原批准人；L0 单人时退化为对自己的约束而不消失）
- **P5 证明修复的验证手段不得由修复者修改。** 生成权与写入权结构分离：改被验对象的人不同时改证明它的用例。｜防的失败：改测试而不是改代码；实现污染证据 ｜删除条件：起始档——生成权与写入权的结构分离自 L2 起才有对象（批准人与验收人具名，见 §3）；L0/L1 的形态是"不在同一次动作里既改被验对象又改证明它的用例"，该自我约束不删
- **P6 "实现完成"的定义包含它的验证手段。** 没有验证手段的完成声明不被接受；验证手段由独立角色对照条目审查。｜防的失败：验证被推到下游、成本更高；局部通过冒充交付 ｜删除条件：机械可判项无需独立审查者，但验收标准仍须来自独立来源
- **P7 实现完成不等于已验收。** 每个条目逐项绑定自己的验收证据（最小字段见[32 证据与追踪](32-证据与追踪.md)），限制公开；证据缺失即尚未验收，中间状态不得混称"完成"。｜防的失败：本地通过被当成已交付 ｜删除条件：写不出（责任结构型：验收是人接受结果的动作，"证据缺失即尚未验收"约束的是宣告完成的权利，不是采集能力）

## 3. 从 L0 到 L3

| 档 | 形态 |
|---|---|
| L0 一人一工具 | 一份清单，自己确认、自己冻结；改动手工标注为验收变更。 |
| L1 一人多会话 | 条目 ID 成为跨会话锚点；每次开工从清单取意图，不从上次会话的记忆里取。 |
| L2 团队 | 批准人与验收人具名；验收变更独立记录；用例覆盖集合与条目集合由检查器对账。 |
| L3 无人值守 | 条目集合既是自动运行的入口也是终止判据；未被条目覆盖的推进不允许自动发生，变更仍回到人。 |

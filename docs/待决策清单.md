3. **默认权限**：AI 可以自主修改到什么程度，哪些操作必须等待人类确认？（第四轮候选答案：D-027/D-028 修订——未登记不放行、应答缺席即拒绝、委托者权限窄于顶层、逐次审批不沉淀、发射类动作需具名人授权）
4. **状态更新责任**：工作项、交接和项目摘要分别由谁更新和批准？（第四轮候选答案：D-016 修订——生成者不是写者，事件推断优先于自报，完成声明引用结构化状态）

## 优先级 B：决定工程闸门

1. 所有项目不可省略的最低 Gate 是什么；如何按 Web、移动端、后端、数据项目增配？
2. 大文件和复杂度使用硬性失败、警告，还是仅在评审中判断？
3. 安全扫描、依赖审计和密钥扫描哪些应为最低强制项？
4. CI 失败时是否禁止 AI 继续新增功能，直至恢复主线健康？

## 优先级 C：衡量规范是否有效

指标候选只在[评估与演进](33-评估与演进.md#metrics-candidates)维护。本轮待决定：从中选 3–5 个核心指标、基线与观测窗口，避免度量本身成为负担。**前提已变（D-055 改动 2）**：涉及产品侧结果的候选指标在旧对象边界下不可选，现在可选，审议时先按 00 §3 的对象判据过一遍。

## 2. 对现有框架的十项实质冲击

### 2.1 第三态在五个位置重复出现，D-014 只堵住了其中一个

D-014 的空集合条款只覆盖"生效规则集合为空"。本轮在五个位置观察到同型漏洞：验证层未执行仍计入通过（WX-08 图 014/015：五层门禁一层都没跑，AI 宣布"可以提交"，仪表盘 88/100）；外部写入超时被记为成功或失败（WX-44 图 017）；审批应答者缺席即放行（WX-29 一手文档反向证明 DSH 选择"缺席即拒绝"）；生成者与验证者同一人仍算"已审"（WX-11、WX-21）；工作单元交接用自由文本承载 blocked 导致下游误读（WX-11 真实 P0）。→ D-029 把"未定（UNDETERMINED）"推广为工作单元粒度的三态纪律，并要求裁定与执行者无关、结构化。

### 2.2 压缩不是"保留清单"，而是一个有触发、有事件、有产物结构的协议

03 §8 原来只规定"压缩保留什么"。本轮四个独立来源指向同一缺口：触发应含行为信号（重复问已确认事项、重复同错、阶段切换）而不只看窗口余量（WX-09 图 010、WX-43）；压缩是可在其前拦截的事件（WX-25、WX-06）；产物分两半——叙事摘要 + 活动工作集原文（Anthropic 一手，经 WX-43 逐句核实）；窗口重建后不变量须重新锚定到高注意力位置（Lost in the Middle 一手：中间位可低于闭卷基线）；失败尝试先转教训再丢弃。另外两条前三轮完全没有的语义：工具返回的存活策略（决策后只留结论 + 回源位置，WX-32 两轮合计反贵的实测）、写侧对称外部化与读降级/写关闭的非对称失败语义（WX-12 千行脚本被截断进生产）。→ D-030。

### 2.3 上下文成本要按三个轴看，原始 token 计数不能代表成本

WX-18/36 同一份数据：token 计数 −22.7%，按缓存价加权后约 −7%，换最新价表后 +7%～+9%——结论随价表变号；WX-32 图 017：总量 −37% 掩盖编排者 +64%。成本须按来源 × 是否重复携带 × 执行单元三轴可观测，报告须声明价表与被报告单元占比。→ 03 §9、06 §8、D-025 修订。

### 2.4 记忆晋升不是"人审 vs 自动"二选一，而是三个正交维度

四个腾讯团队（WX-31/33/38 + WX-27）与 8 篇核实过的自进化论文（WX-20）共同显示：全量人审导致沉淀停滞与审核疲劳（WX-31 图 005：引用 222 次的条目仍待审），全自动导致污染（WX-20：代理验证 100% 通过而权威验证 75%）。裁决：入池条件（客观交付信号）× 权威性（owner）× 影响面；自动晋升仅限"已登记判定器覆盖 ∧ 局部影响面"且可事后否决；全局规则、安全边界、评估集、回滚、冷启动种子必经人审；审批点从写入前后移到进入权威载体或默认可见范围前。→ D-033（取代 D-007）、D-034（置信态 强/弱/影子 + 使用方式 + 注入即记账）。

### 2.5 知识过期有两种机制，且判据一"代码不写"在大仓不可执行

WX-06（git hash 差异机械判过期，真实事故：调到废弃接口链路全通结果错）与 WX-27（经验型知识源是事件不是 revision，只能触发复核）给出两类过期机制。WX-14/06/27 三个团队都维护代码派生的导航地图，WX-25 的 Bazel 案例显示"代码可读"的事实模型仍反复用错——这与已接受的 D-020 判据一"代码与运行环境→不写"直接张力。裁决：派生知识作为**声明的缓存**允许存在，条件是绑定源版本、机械对账、人工区受保护且有覆盖权、变更只追加（D-032）；判据一本身的修订作为 **D-040 修正案**提交 Alan，本轮不改 09 章。

### 2.6 验证基础设施自己会撒谎，Harness 需要第四观测面

WX-42 同类错误一年犯四次（覆盖率采集失败显示 0%、判分器格式错 0→98 分、评分器粒度错配、参照测试自身有 bug）；WX-08 检查器假设的目录已改名却长期标"已有问题"；WX-44/34/02 各自独立要求"文档是否被读到、Skill 是否触发、Gate 拦住真问题还是误伤"有计数。→ D-038：检查器结构假设过期判故障；拦截层须独立失效探测；判分器须效度证据；无计数不得判有效。06 §1 新增"Harness 机制级"评估层。

### 2.7 D-024 的"Gate 上限"要拆成两类，对策不是减 Gate 而是让 Gate 便宜到能真判

WX-42 主张"会话外确定性 check 多多益善"与 D-024 表面冲突，实际对象不同：事实门禁（判据是可直接观察的确定事实）上限由误报率约束；人工判断检查点上限由判断带宽约束，须集中在少数状态转换处（Anthropic 一手：审批钩子放发布不放构建）。WX-26（= ATT-H）被前三轮漏掉的对策：裁决项/证据/推荐前置，全文与 diff 作附录——呈现格式属 Gate 合同。代理指标（"已读过""已声明"）只能提醒不得阻断（WX-42 同一 hook 里两条规则的不同命运）。→ D-024 修订、05 §1 四级阶梯、05 §3。

### 2.8 长任务的恢复、活性与写入权

三条前三轮空白的语义：活性不变量——进行中单元须绑定可探活执行者与新鲜度信号，静默卡住比失败更危险（WX-11 健康扫描任务停 5～6 天，平台自身 P0）；恢复语义——两份一手框架文档给出相反的重跑范围，语义层只能写"不得丢失已确认结果 + 不可逆副作用幂等或有回执 + 外部写只在声明窗口且失败入待补偿"（D-036）；生成权与写入权结构分离——AI 只产候选，进入受治理记录源须经独立写者，证明修复的测试不得被修复者修改（Anthropic 一手 hook 禁改测试；WX-07 下游顺手改验收标准；WX-42 空 commit 循环）（D-037，与验收条目单一来源合并）。

### 2.9 D-021 要三分类，评估器与评估集自身也会过期

WX-26 图 008（前三轮丢失）给出 D-021 三元组的实例集，并显示到期规则多数**反转为负作用**而非仅冗余；Anthropic 一手：评价者≠被评价者是结构性偏差，随模型变强只是"价值边界外移"。→ 规则三分：能力补偿类（须删除条件）/ 组织信息类（不过期，形态迁移）/ 责任结构类（声明无到期）；"可复现失败"允许已观察与已构造两种来源（否则 05 §3 全部动作前 Gate 不满足 D-021）；到期审计三种触发并存。WX-44 转述 Boris 一手：eval 自身 1～3 代即饱和；WX-38 图 026 把"评测 case 过时→更新评测集"做成自动分支——是 D-023 的逃逸口。→ D-035 评估器与评估集治理。

### 2.10 跨工具通用性首次获得一手验证材料，也首次暴露判据的间隙

WX-29/37（DSH 一手文档）、WX-17/25（同一语义在两宿主字段名不同）、WX-30（网关冻结 + 工具侧复核两处检查）为 D-020 的"两种机制类型检验"提供了首批真实样本，并抽象出十个维度的[机制类型清单](../../附录-载体实例/机制类型清单.md)（只写类型不列工具）。五张卡片各自核对到"载体先于规范过期"的实例（钩子输出格式从官方文档消失、MCP 成文 5 天后换代、触发词改名），进入[载体过期登记](../../附录-载体实例/载体过期登记.md)。判据一的间隙（运行观察提炼的经验既不在公开语料也不能从代码读；"可推断"不是公理）→ D-040。

# IMP · 导入导出

### IMP-001 · 导入模板版本化
- 可观察结果：每个导入模板有版本号写在首行；系统拒绝未知版本并提示当前支持的版本列表
- 目标环境：prod
- 优先级：P0
- 状态：frozen（Zhao，2025-05-06）
- 来源：契约 FILE-新品导入模板
- 派生：WI-0024

### IMP-002 · 导入是两阶段：预览后提交
- 可观察结果：上传后先返回逐行校验结果与归类，不改任何数据；用户确认后才提交；提交是原子的（全部成功或全部不写）
- 目标环境：prod
- 优先级：P0
- 状态：frozen（Zhao，2025-05-06）
- 派生：WI-0024

### IMP-006 · 新品导入预览给出每行的四类归属与依据
- 可观察结果：预览结果每行含 `category ∈ {新品, 编辑经营范围, 调价, 一品多码, 待确认}` 与 `basis`（命中的 SKU、条码、名称相似度）；"待确认"行可由用户手动指定类别后提交
- 目标环境：staging → prod
- 优先级：P0
- 状态：frozen（Zhao，2026-08-04）
- 派生：WI-0151；CAT-011

### IMP-007 · 导入结果可导出为四份已填写模板
- 可观察结果：提交后可下载四份文件（新品导入、编辑经营范围、调价单、一品多码），格式与商品部现用模板一致，附一份待确认说明
- 目标环境：staging → prod
- 优先级：P1
- 状态：frozen（Zhao，2026-08-04）
- 派生：WI-0151

# CAT · 商品主数据

### CAT-001 · SKU 唯一且条码可多对一
- 可观察结果：同一 SKU 可绑定多个条码（一品多码）；任一条码在全企业唯一指向一个 SKU；新增重复条码被拒绝并返回冲突的 SKU
- 目标环境：prod
- 优先级：P0
- 状态：frozen（Zhao，2025-03-10）
- 派生：WI-0003；tests/unit/catalog/test_barcode_uniqueness.py

### CAT-002 · 经营范围按门店生效
- 可观察结果：SKU 的经营范围是门店集合；不在范围内的门店 POS 不接收该 SKU；范围变更在下一次推送周期（≤ 15 分钟）内生效
- 目标环境：prod
- 优先级：P0
- 状态：frozen（Zhao，2025-03-10）
- 派生：WI-0008；WI-0031（推送周期）

### CAT-007 · 商品档案变更留痕
- 可观察结果：名称、分类、条码、经营范围、供应商的每次变更有操作人、时间、前后值；可按 SKU 查询完整历史
- 目标环境：prod
- 优先级：P1
- 状态：frozen（Zhao，2025-04-02）
- 派生：WI-0019

### CAT-011 · 新品导入自动拆分四类
- 可观察结果：上传新品导入模板后，系统按条码与名称与现有档案比对，把每行归入①新品②编辑经营范围③调价④一品多码四类之一，或标"待确认"；每行给出归类依据（命中的 SKU/条码）
- 目标环境：staging → prod
- 优先级：P0
- 状态：frozen（Zhao，2026-08-04）
- 来源：商品部 2026-07 需求；F-029（人工分类错误率）
- 派生：WI-0151；IMP-006

### CAT-012 · 一品多码导入不覆盖主条码
- 可观察结果：导入行命中已有 SKU 的名称但条码不同时，新条码追加为副条码，主条码不变；副条码数量上限 8，超出拒绝并提示
- 目标环境：staging → prod
- 优先级：P0
- 状态：frozen（Zhao，2026-08-04）
- 派生：WI-0151

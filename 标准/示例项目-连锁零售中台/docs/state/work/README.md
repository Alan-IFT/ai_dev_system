# 工作项

一件一文件，`WI-<四位序号>-<短名>.md`。序号只增不复用。**工作项是任务的实时状态源**；交接是它的临时快照；STATUS 只索引当前重点。

## 状态机

`planned → in_progress → in_validation → done`；任一状态可 `blocked`（显式，带原因/解除条件/责任人/复查日）；`cancelled` 记原因。转换记录一行一次：`from → to | 时间 | 执行者 | 分支@HEAD | 依据 | 三态`。

活性：`in_progress` 超 5 天无转换记录，周一巡检转 `blocked`。

## 文件骨架

```
# WI-NNNN：<可验收结果>
work_item_id / state_revision / updated_at / 状态 / 负责人 / 变更级别
## 工作区身份        repository / branch / HEAD / 未提交改动 / 目标环境
## 目标与范围        目标 / 范围内 / 范围外
## 验收映射          acceptance_id | 主张 | 目标环境 | 证据（指针）
## 上下文            必读（精确到片段）/ 条件读 / 明确不读 / 本次不变量
## 影响与风险        模块 / 数据迁移 / 契约 / 安全 / 兼容 / 回滚
## 实施计划          阶段与顺序
## 闸门记录          gate | 结果 | 证据 | 豁免
## 验收证据          六字段，逐条绑 ID
## 当前状态          已完成 / 阻塞 / 下一原子动作 / 最后验证时间
## 状态转换记录
## 候选沉淀          本次发现的"只有本项目知道的事"，周一裁
## 遗留与风险接受
```

预算 150 行；过程记录进 `artifacts/<WI>/`。

# 术语表

只放本项目特有的、代码里读不到含义的词。通用工程术语不收。

| 术语 | 含义 | 权威 |
|---|---|---|
| 一品多码 | 一个 SKU 绑定多个条码；一个主条码、≤ 8 个副条码 | CAT-001、CAT-012 |
| 经营范围 | SKU 可售的门店集合；不在范围的门店 POS 不接收该 SKU | CAT-002 |
| 四类拆分 | 新品导入行归为：新品 / 编辑经营范围 / 调价 / 一品多码（或待确认） | CAT-011、IMP-006 |
| 流水回传 | 门店 POS 把销售流水推回本系统；按厂商流水号幂等 | POS-003 |
| 静默 | 营业时间内门店超过阈值无流水 | POS-009 |
| 回执 | 每笔外部写在 `platform.idempotency_receipt` 的登记；对账用 | ADR-0009、INV-04 |
| outbox | 业务事务内写入、由投递器异步发出的事件暂存表 | ADR-0004、ADR-0009 |
| expand / migrate / contract | 破坏性契约变更的三阶段 | INV-07、ADR-0007 |
| 日结 | 门店每日销售汇总与现金核对 | settlement |
| 盘点锁定 | 盘点期间出库排队 | inventory 配置 |
| 工作区身份 | 仓库 + 分支 + HEAD +（环境）；每条状态记录必带 | INV-08 |
| 三态 | PASS / FAIL / UNDETERMINED；未定不折算 | AGENTS.md §5 |

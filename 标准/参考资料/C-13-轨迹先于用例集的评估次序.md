## 原文结论与适用限制

可支持的表述：该指南主张**先看真实轨迹、后建数据集与可重复 eval run**——调试行为阶段用轨迹，确定了什么算成功之后再转向数据集以获得可重复性；评估对象包含中间决策与约束遵守（是否选对工具、工作流是否违反指令或安全策略），不只最终输出。本轮抓取核对另确认一处**该指南没有覆盖的内容**：它不讨论评分器本身的可信度与校验方法。

适用限制：这是产品指南，直接适用对象是该厂商定义的 agent workflow；本仓库阅读卡已把"用于 AI 编码 Harness"标记为本项目的外推假设（RC-006），要求以项目 Case 验证。本卡沿用该标记，不把指南结论当作对编码系统的既定事实，也不引用其任何产品功能名称、界面路径与配置项。

## 缺口、采纳与不采纳

**采纳一：判据未稳定时不先建用例集与评分器。** [03 §11.1](../03-Agent信息获取与上下文管理.md#context-evals) 开头写"任务负责人**事先定义**成功／失败与允许变化"，隐含判据已经存在；对首次纳入评估的任务类型、或判据刚被推翻的情形没有出口。缺这一步的失败方式是可追溯的：在成功标准还在变动时构造的用例集与评分器会把当时的错误目标固化，此后所有比较（包括 [C-08](C-08-评估回流与自进化回路.md) 的挑选集／验证集分离、预算对等比较）都在这个错误目标上进行，且门控每次都通过。触发条件：新任务类型首次纳入评估，或既有成功判据被一次评估结果推翻。责任角色：任务负责人定判据，维护者组织用例。工件：真实运行轨迹与由其归纳出的成功／失败描述。失败处置：判据仍不可判定时该轮记未定，不建用例集、不出比较结论。删除条件：项目已有稳定的人工验收判据可直接复用时，本步骤可跳过并记录理由。

**已由既有卡覆盖，不重复采纳**：
- **评估对象含工具选择、交接与规则遵守，不只最终输出。** 03 §11.1 表格的"并行委托"行（收口、写集冲突、迟到）、"注入与权限"行（实际读取／外发／工具副作用）、§11 的**行动路径**层（步骤数、补偿性检索、修改与测试轮次）已覆盖；行动路径层由 [C-06](C-06-上下文给对而非少给.md) 采纳，工具与委托侧由 [C-04](C-04-Anthropic-Agent评估.md)、[C-03](C-03-Anthropic多Agent研究系统.md) 覆盖。本轮不重复采纳。
- **用轨迹定位是模型、检索、工具还是编排的问题。** 03 §11.1 末段"先从轨迹区分模型、检索、工具、编排及评分器问题，修复后复跑受影响用例"已有，[C-04](C-04-Anthropic-Agent评估.md) 覆盖。不重复采纳。
- **结果回流与回归集。** [C-08](C-08-评估回流与自进化回路.md) 上一波已重写，不重复采纳。

**核对结论一（无修订）：评分器可信度。** 本轮核对确认该指南**不讨论**评分器可信度。03 §11.1 现有的"先用已知正确结果与故意缺证／错误结果检验评分器，避免恒通过或恒拒绝""模型判定器须与人校准""被测执行者不得修改评分器或答案"依据仍挂 [C-04](C-04-Anthropic-Agent评估.md)，本轮不改动、不改挂、不加强。记录此项的目的是防止后续误以为本材料为该条提供了第二份佐证。

**核对结论二（无修订）：外推标记。** 本仓库阅读卡的 RC-006（agent workflow → AI 编码 Harness 属外推）对应 03 §11 已有的"优化手段按**任务形态**登记适用与不适用范围……至少在两类形态上各取样；方向不一致时分形态登记，不做跨形态外推"。同一条纪律已在正文，不新增。

**不采纳一：该指南的产品对象与流程命名（trace / dataset / eval run / grader 的具体形态与控制台流程）。** 属宿主与产品绑定的操作细节，按 [03 §12](../03-Agent信息获取与上下文管理.md#capability-acceptance) 应作为按版本登记的接入记录，不写进正文。

**不采纳二：guardrail 作为一等评估对象的独立行。** 03 §11.1 表格已有"注入与权限"行，且 §6.1／§6.2 规定了边界本身；再加一行会与之重叠，违反 §13 的"清单只增不减"纪律。

## 验证办法

- 次序：抽查最近一次新增的评估用例集，检查其判据的来源记录——若判据只来自设计讨论、没有对应的真实轨迹，判为待核查，须补轨迹或记未定。
- 固化错误目标：取一个成功判据发生过变更的任务类型，检查变更前构造的用例集是否随之重建；沿用旧用例集而未重建即判失败。
- 评分器可信度（沿用 C-04 的办法，不新增）：用已知正确与故意错误的结果各跑一遍，出现恒通过或恒拒绝即判失败。
- 以上均未在本仓库运行，本轮全部记未定。

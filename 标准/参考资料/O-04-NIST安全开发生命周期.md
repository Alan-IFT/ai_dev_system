# O-04 · Secure Software Development Framework (SSDF) Version 1.1

- 作者：Murugiah Souppaya、Karen Scarfone、Donna Dodson；机构 NIST。
- 原文：[SP 800-218 发布页](https://csrc.nist.gov/pubs/sp/800/218/final)；[PDF 正文](https://nvlpubs.nist.gov/nistpubs/SpecialPublications/NIST.SP.800-218.pdf)。
- 发布：2022-02-03（发布页）；访问：2026-09-08。采用已明确版本的 1.1，不声称这是未来或所有场景的最新合规基线。
- 实读范围：执行摘要；PO.5 环境保护；PS.3.2 来源记录；PW.1 风险建模与决策；RV.1.3、RV.2、RV.3 漏洞响应。未逐项核验全表和引用标准，不声明完整 SSDF 符合性。

## 原文结论与边界

安全实践贯穿现有开发生命周期，按风险与结果实施；设计风险要跟踪，开发环境要保护，发布组件要能追溯，漏洞要评估、处置并反馈根因。框架允许组织选择实现方式，不是单一工具清单，也不能由一次扫描证明完成。

## 本项目采用

补充现有安全基线之外的资产到修复闭环：威胁记录、环境权限、组件到运行版本映射、漏洞负责人和复查证据。本文字段、检查时机与严重度处理方式是工程落地选择，不是 NIST 对本项目的法律要求。

- 已落地：[04 安全与供应链](../04-可靠性安全与运行维护.md#security-supply-chain)。
- 不采纳：全量照搬参考标准、无条件建设专职安全团队、扫描零命中等于没有风险。
- 验证：给定一个依赖组件能定位实际运行制品；给定越权风险能定位控制与反例测试；无补丁漏洞仍有缓解/例外到期路径。
- 裁剪：可使用现有工单系统和组件清单，独立安全文档按风险建立；生产环境授权控制不能靠 Agent 文本提醒代替。

# 测试

- **金字塔**：单元 > 集成 > 端到端。端到端只覆盖关键路径——它最慢最脆
- **测试描述行为，不描述实现**。测试名是一句话事实，不是被测函数名
- **先红后绿**：修 bug 必须先写一个能复现它的失败测试，看它红，再改代码，看它绿
- **证明修复的测试，不得由修复者修改**——这是结构要求，不是礼貌
- 新代码带测试
- **覆盖率是信号不是门**。不设百分比阈值当 Gate：那会奖励无断言的测试
- **测试必须确定性**。有 flaky 测试就修它或删它，**不许重跑到绿**——重跑到绿等于把随机数当验收

## 反模式（出现即停）

- 改断言让它通过
- 加 `skip` / `only` 后提交
- 把失败测试注释掉
- 用 sleep 等异步

# 收工与交接

先自己取工作区身份（本模板不注入命令结果，由你现取）：跑 `git status -sb` 与 `git log --oneline -5`，
取到的分支、HEAD、未提交改动写进交接。取不到（不在 git 仓、命令失败）就写 `unknown`，不编。

按 01 §4.2 收工前与 03 §8.1 做，**模板用本项目自己的**：路径按入口文件的加载合同或
`governance/project.yaml` 的 `layout.artifacts` 找；找不到就停下问，不自拟格式。

1. 完成声明各附证据六字段（01 §4.2 收工前第 1 条）；当时没记的写"未记"，不事后补造。
2. 更新当前工作项：状态、转换记录、下一原子动作、最后验证时间。
3. 写交接，两半都要（03 §8.1）：
   - 叙事摘要：目标与范围、已生效决策、工作区身份（用上面现取的分支、HEAD、未提交改动）与状态版本、
     已完成项与证据位置、未完成原因、未解决错误、风险、下一个原子动作、失败尝试的假设及证据；
   - 活动工作集引用：正在编辑或验证的文件按路径列出，不摘要。
4. 交接写不进去就如实报告，不声称已交接。

写完回报交接文件路径与工作项的新状态版本。

# 安全

- **最小权限**：agent、CI、服务各自只拿本次需要的权限，默认只读
- **凭据永不进仓库**：不进代码、配置、提交信息、日志。用环境变量或密钥管理
- **输入即不可信**：所有外部输入（用户、API、文件、**模型输出**）先校验再用。参数化查询，绝不拼 SQL
- **OWASP Top 10** 作为评审清单；对外服务另加 **ASVS L1**
- **供应链**：锁文件必须提交；新依赖须说明为什么不用现有的；定期跑依赖审计

## agent 不得处理

真实凭据 · 支付信息 · 生产库的写操作 · 绕过验证码 · 把数据发到用户没指定的地址

## 发现泄露时

**先撤销凭据，再谈别的。** 从 git 历史里删掉不等于没泄露——已推送的一律按已泄露处理。

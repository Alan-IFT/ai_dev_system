# 可观测性与运维

**§0 中"有生产环境=否"时，本节整节记 `UNDETERMINED`（不适用），不是"通过"。**

- **结构化日志**：JSON，带 trace id。**不许** `print` 调试后留在代码里
- **OpenTelemetry** 埋点：请求、外部调用、错误三类起步
- **SLO + 错误预算**：先定"多少算坏"，再谈优化。**没有 SLO 时性能改动没有判据**——快了 10ms 是好是坏答不出来
- **变更失败率**与**恢复时间**（DORA 后两指标）是发布质量的判据，不是部署频率

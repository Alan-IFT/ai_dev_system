# 模板目录

governed_by：D-014、D-020

**本目录整体属于载体实例，效力为零。**

模板是语义要求在"文档 + 表格"这一种载体上的实现。其中：

- **字段集合属于语义**——由对应规范正文定义，换载体不变；
- **文件形态、章节顺序、表格布局、字段名拼写属于载体**——换一种工具或存储方式即需重写。

因此模板不构成落地要求：用任务系统字段、结构化数据或其他形态承载同一套字段集合，同样满足规范。模板中的状态值按 D-014（标准仓 `docs/08-规范效力元治理.md`）的效力语义填写；实际效力以生效登记表（标准仓 `docs/决策日志.md#effective-register`）为准。

模板中出现的版本控制字段（仓库、工作树、分支、提交标识）是工作区身份（标准仓 `docs/20-状态工件.md#workspace-identity`）的**一种**探测形态，不是必填字段。

**要一套可直接采用的项目管理标准与示例项目，读 [标准/](../标准/README.md)**：四篇标准（项目管理、架构描述、Agent 信息获取与上下文、可靠性安全与运行维护）加一个 14 模块、18 个月的示例项目文档树。下面这些模板是它的字段级展开。

**先读[文件树与落地路径](文件树与落地路径.md)**：它把下面这些模板装配成一棵树，按 L0～L3 四档给出"这一档需要哪几个文件"，并说明**部件数不等于文件数**（见其 [§1](文件树与落地路径.md#not-14-files)）。

- **[AGENTS.md](AGENTS.md)：agent 工作规范的常驻核**，按行业推荐标准配置。复制到项目根即生效（DSH / Claude Code / Codex 三家都读这个文件名），只填 §0。**只放"晚一秒就来不及"的规则**：权威位置、不可逆动作、三态、停机条件。
- **[agent-skills/](agent-skills/)：同一套规范的按需层**，7 份，复制到 `<项目根>/.agents/skills/`。DSH 按 rank 200 自动扫描，**只有 description 常驻、正文命中才加载**。切分判据是"这条在它该生效那一刻必须已在上下文里吗"——是则进常驻核，否则进这里。
- [Default Context Contract](CONTEXT_MANIFEST.md)：唯一声明默认/按需上下文入口。落地为入口 `AGENTS.md` 的加载合同一节，不另建文件。
- [PRD](PRD.md)：定义目标、范围和稳定验收 ID。
- [架构说明](ARCHITECTURE.md)：记录当前有效系统设计。
- [项目状态](PROJECT_STATUS.md)：里程碑摘要，不承载实时任务步骤。落地为 `WORK.md` 的摘要部分（01 §3.1 大项目树为 `docs/state/STATUS.md`）。
- [工作项](WORK_ITEM.md)：实时任务状态源与验收到证据映射。
- [会话交接](SESSION_HANDOFF.md)：带 worktree/HEAD/revision 的临时快照。
- [ADR](ADR.md)：记录决策效力、范围、取舍与验证。
- [Eval Manifest](EVAL_MANIFEST.md)：固定 Harness 实验版本、阈值、结果和晋升链。

模板章节按需填写，但身份、效力、版本、环境和责任字段不能因“暂时未知”而静默删除；未知应显式写 `unknown`，不适用写 `N/A + 理由/批准人`。
